# Capstan Governance Records

These records define the current SaaS boundary and release claims. They are source-controlled so
the product does not rely on task history for security or delivery state.

- `saas-readiness.md`: SaaS invariants, completed foundation, and production blockers.
- `authentication-authorization.md`: tenant identity and authorization contract.
- `deployment-and-update.md`: supported deployment profiles and release procedure.
- `project-tracker.md`: current SaaS implementation status.
- `findings-register.json`: canonical open and closed SaaS findings.

The documents make no certification or broad compliance claim. They must be updated in the same
change that closes or introduces a material SaaS boundary, release, identity, or isolation gap.
